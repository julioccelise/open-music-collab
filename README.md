# Open Music Collab

A collaborative repository where anyone can share recordings of individual instruments, lyrics and vocals, and turn them into finished songs through pull requests.

## Structure

```
samples/
  guitar/        # instrument recordings (more folders, e.g. bass, piano, can be added when needed)
albums/          # finished songs and productions
```

## Any genre, any style

There are no rules about genre or style. Albums and songs can be anything: rock, folk, techno, background music, whatever you like. Lyrics can be written in any language. The goal is to have fun.

## AI usage

Music, lyrics and voice generated with AI are **not allowed** in this repository. All audio and lyrics must be created by humans.

AI tools may be used for supporting files, such as metadata and README files, and to write pull request descriptions.

## How to contribute

1. Fork the repository and create a branch.
2. Add your recordings or lyrics under `samples/`, or your productions/mixes under `albums/`.
3. Open a pull request describing what you added or changed.

Prefer lossless audio (WAV/FLAC) and include the BPM and key in the contribution's README when known.

## Crediting authors (required)

**Every contribution and every song must include its own `README.md`** in its folder that credits all authors. At minimum:

```
# Title

- Author(s): Name (link or handle)
- Role: e.g. guitar, lyrics, mixing
- Date: YYYY-MM-DD
- BPM / Key: (optional)
- Based on: links to the samples or songs this work uses (if any)
```

Example: `samples/guitar/my-riff/README.md` next to `my-riff.wav`.

Productions in `albums/` must credit **everyone** whose samples were used.
